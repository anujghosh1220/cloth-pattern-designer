# Draping Threads - Easy Installation Guide

## 🎯 For Non-Technical Users

**File to Download:** `Draping Threads Setup 1.0.0.exe` (234 MB)

---

## 📥 Step-by-Step Installation

### 1. Download the Installer
- Look for the file named: **"Draping Threads Setup 1.0.0.exe"**
- Save it to your Desktop or Downloads folder

### 2. Run the Installer
- **Double-click** on "Draping Threads Setup 1.0.0.exe"
- If Windows asks "Do you want to allow this app to make changes?" → Click **Yes**
- If Windows Defender shows a warning → Click **"More info"** → **"Run anyway"**

### 3. Follow the Setup Wizard
- Click **Next** on the welcome screen
- Choose where to install (recommended: keep default location)
- Click **Install**
- Wait for installation to complete
- Click **Finish** when done

### 4. Launch the App
- **Desktop Shortcut**: Look for "Draping Threads" icon on your desktop
- **Start Menu**: Click Start → All Programs → Draping Threads
- **Double-click** the icon to start the app

---

## ✅ What Happens After Installation

1. **App Window Opens**: A desktop window will appear
2. **Loading**: The app starts automatically (takes 10-30 seconds)
3. **Ready to Use**: Login screen appears - use username: **admin**, password: **admin2214**

## 🛠️ Troubleshooting

### "Windows Protected Your PC"
- Click **"More info"**
- Click **"Run anyway"**

### App Won't Start
- Restart your computer
- Try running as Administrator: Right-click → "Run as administrator"

### Can't Find the App
- Check your Desktop for "Draping Threads" icon
- Click Start → Type "Draping Threads" → Press Enter

### Slow Loading
- First launch may take 30-60 seconds
- Be patient, the app is starting its internal server
