# Draping Threads - Portable Version 
 
## 🎯 Super Easy - No Installation Required! 
 
### Step 1: Double-click START_APP.bat 
### Step 2: Wait for app to open (may take 30-60 seconds) 
### Step 3: Login with: admin / admin2214 
 
## 📋 What Happens 
- App automatically finds or installs Python 
- Flask is installed automatically if needed 
- Application starts in your web browser 
 
## 🆘 If You See Errors 
- "Python not found" - Install Python from python.org 
- "Flask not found" - App installs it automatically 
- "Port 5000 in use" - Close other apps and restart
